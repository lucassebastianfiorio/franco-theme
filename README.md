# franco-theme

Theme WordPress + WooCommerce personalizado para Franco Deportes.

- **Versión:** 3.9.1 (versión estable base)
- **Autor:** Lucas Fiorio / Franco Deportes Team
- **Compatibilidad:** WordPress 6.0+, WooCommerce 7.0+, PHP 7.4+

## Actualizaciones automáticas
Este tema cuenta con un verificador automático nativo integrado con los releases de GitHub (`lucassebastianfiorio/franco-theme`). Al publicar un nuevo Release o Tag en este repositorio, WordPress lo notificará en el panel de administración como cualquier otro tema.
